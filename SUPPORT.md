# Support — Not-Humans-Lab (umbrella)

This is a triage front door, not a substitute for each sub-project's own `SUPPORT.md`. GitHub only auto-surfaces a `SUPPORT.md` on the exact repo an issue is filed against — once daily-dose/nh-deck/nh-skills exist as separate repos, each needs its own copy for that to actually trigger.

## How to get help

1. **Know which project it's about?** Go to that project's own repo and its own `SUPPORT.md` (once it exists) — that's the fastest path.
2. **Not sure which one?** Describe what you're trying to do here and we'll route it.

| Using... | Go to |
|---|---|
| daily-dose (the daily digest) | daily-dose's own `SUPPORT.md` (not yet scaffolded) |
| nh-deck (the presentation CLI) | nh-deck's own `SUPPORT.md` (not yet scaffolded) |
| nh-skills (the agent skills collection) | nh-skills's own `SUPPORT.md` (not yet scaffolded) |

## How to file a good bug report

Include: which project, what you expected, what actually happened, exact steps to reproduce, and your OS/runtime version.

## Response-time expectations

Best-effort, no formal SLA — this is a small, largely solo-maintained suite.

## Security issues

Do **not** file a public issue for a security vulnerability — see `SECURITY.md` for private disclosure instructions.
