## Entry types (for when entries start landing here)

- **user/team preference** — a stated preference that should shape future work across the suite
- **feedback** — a correction given and accepted, applicable to more than one sub-project
- **project history** — a decision + why, not derivable from code or git log, that matters across projects
- **reference** — a pointer to where authoritative info lives externally (e.g. "the real obra/superpowers spec/plan format lives at github.com/obra/superpowers")

## Promotion rule

A lesson learned independently inside two or more of daily-dose/nh-deck/nh-skills' own `memory.md` files gets copied up here, with a one-line pointer left behind in each project file. Don't duplicate — link.

## Maintenance

Keep this index short. Once an entry needs more than 2-3 lines, push detail into a per-topic file under `docs/memory/<topic>.md` and link it from here instead of growing the index itself.
